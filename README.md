## 🌟 核心特性与性能榨取

本脚本不仅仅是部署工具，更在网络底层进行了极限优化，专为看视频和打游戏打造：

- **🚫 告别“不信任服务器”弹窗**：内置 `acme.sh`，安装时只需输入域名，自动申请并配置 Let's Encrypt 权威受信任证书。客户端直连，不再弹红标警告！
- **🚀 极限网速优化（自带三板斧）**：
  1. **开启 BBR 拥塞控制**：自动修改内核开启 BBR，极大提升弱网/高延迟环境下的吞吐量。
  2. **开启 UDP (DTLS) 传输**：AnyConnect 原生支持，摒弃臃肿的 TCP，使用 UDP 传输数据，彻底解决网络拥堵时的“队头阻塞”，打游戏延迟更低。
  3. **开启 MTU 自动发现与无损传输**：动态适配最大传输单元，并去除了冗余的流量压缩（现代流量已加密压缩），大幅降低服务器和设备的 CPU 消耗，提升极致网速。
- **📱 智能下发服务器列表**：全自动构建 `profile.xml`。客户端首次成功连接后，会自动将当前节点保存到客户端列表中，下次连接一键直达，告别繁琐的手动输入。
- **🌏 100% 纯全局代理接管**：默认开启全局路由（`route = default`），去除所有国内分流白名单。连上 VPN 后，所有设备的全部流量（含国内 APP 如富途牛牛、微信等）强制通过 VPN 隧道转发，无死角伪装海外 IP！
- **🔧 交互式智能控制台**：支持一键安装、卸载、启动、停止、添加/删除/禁用用户等快捷操作。

## 🚀 快速安装

**支持系统**：Debian 9+ / Ubuntu 18.04+ （暂不支持 CentOS）

### 安装前的准备（必读）
1. **准备一个域名**（推荐）：要想客户端不报安全警告，请提前将你的域名（如 `vpn.example.com`）解析到这台服务器的公网 IP 上。
2. **开放端口**：
   - 确保服务器的安全组/防火墙开放了 **`80`** 端口（仅在申请证书时短暂使用）。
   - 确保开放了 **`443`** 端口（TCP & UDP 协议均需开放，建议使用默认的 443 端口，客户端即可免填端口号）。
3. **环境干净**：确保服务器上没有安装 Nginx/Apache 等占用 `80` 端口的网页服务，否则证书可能申请失败。

### 一键安装命令
在终端中以 `root` 用户运行以下命令：

```bash
wget -N --no-check-certificate https://raw.githubusercontent.com/lgdglgc/ocserv88/master/ocserv.sh && chmod +x ocserv.sh && bash ocserv.sh
```

> **提示**：安装完成后，以后只需在终端输入 `bash ocserv.sh` 或 `./ocserv.sh` 即可随时唤出管理菜单，管理账号或修改配置。

## ⚠️ 避坑指南与常见问题

### 1. 为什么连接时提示 `DTLS handshake failed` 或者速度很慢？
这是因为你的云服务器提供商（如阿里云、腾讯云、AWS等）默认屏蔽了外部 UDP 端口。
**解决办法**：请务必登录你的云服务器控制台，在**【安全组 / 防火墙】**设置中，放行你安装时配置的端口（默认为 `443`）的 **TCP 和 UDP 协议**。打游戏和看超清视频必须通 UDP！

### 2. 安装时提示“证书申请失败，回退到自签证书”？
原因通常有两个：
1. 你的域名解析还没有生效，或者你填错了域名。
2. 你服务器的 `80` 端口被封锁，或者被宝塔面板、Nginx 等程序占用了。

### 3. 连接成功但无法上网？
可能是服务器自带的安全策略阻挡了流量转发。管理菜单会自动识别出口网卡并配置 iptables，如果识别错误，可以卸载后重新运行脚本，在提示网卡名时手动输入正确的网卡（如 `eth0`）。

## 📱 客户端推荐

只要支持标准的 AnyConnect 协议的客户端均可连接：

- **Windows / macOS**：搜索下载 `Cisco AnyConnect Secure Mobility Client`，或者最新版的 `Cisco Secure Client`，也可以使用开源的 `OpenConnect GUI`。

连接时直接输入：`你的域名` （如果端口使用的是默认的 443 就不需要加端口后缀）。

## 🛠 高级玩法：向客户端下发多个服务器列表

> **💡 全新升级**：当前版本安装脚本已经**完全自动化**了基础的下发功能！安装时脚本会自动提取你的域名或 IP，并在客户端首次连接时自动保存到列表中。

如果你拥有多个节点（例如美国、日本多台服务器），想让客户端一次性保存所有的节点地址供自由切换，你可以手动在这个文件里添加更多节点。

修改文件：
```bash
vi /var/lib/ocserv/profile.xml
```

在文件中添加或修改如下 XML 节点：
```xml
<ServerList>
    <HostEntry>
        <HostName>我的美国节点</HostName>
        <HostAddress>us.yourdomain.com:443</HostAddress>
    </HostEntry>
    <HostEntry>
        <HostName>我的日本节点</HostName>
        <HostAddress>198.51.100.1:8443</HostAddress>
    </HostEntry>
</ServerList>
```
*(注：最新的安装脚本已默认开启下发功能并创建了基础的文件结构，你只需照猫画虎添加 `<HostEntry>` 即可。)*
