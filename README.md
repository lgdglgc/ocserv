# 🚀 Ocserv (AnyConnect) 纯全局·极致网络优化一键部署脚本

基于现代 Linux 发行版深度重构与升级的高性能 Cisco AnyConnect VPN 服务端一键部署方案。
**专为对网络有极高要求、需要 100% 隐藏国内 IP 轨迹的用户打造（如跨国金融交易、严格风控业务环境）。**

---

## 🌟 核心特性与性能榨取

本脚本不仅是一键部署工具，更在系统底层网络层面上进行了“满血级”的极限优化：

- **🌏 100% 纯全局代理接管**：彻底移除了传统脚本中携带的冗长国内 IP 分流白名单。默认开启强制全局路由（`route = default`），连上 VPN 后，所有设备的所有流量（含富途牛牛、微信等所有国内 APP）将强制进入 VPN 隧道，实现**无死角伪装海外真实 IP**，告别风控！
- **🚫 告别“不信任服务器”红锁弹窗**：全自动申请 Let's Encrypt 权威机构证书（基于 `acme.sh`）。客户端直连秒进，拥有象征安全的绿锁，拒绝不受信任的假证书报错。
- **🚀 极限内核网络优化（满血提速补丁）**：
  1. **BBR + FQ 拥塞控制**：无视晚高峰网络丢包，大幅提升国际长链路传输速度。
  2. **TCP 缓冲区全面扩容**：暴力提升 TCP 读写缓冲区（`rmem/wmem`），跑满跨国大带宽限制。
  3. **海量并发与端口复用**：突破 Linux 默认连接数限制（`fs.file-max`），开启 `tcp_tw_reuse`，哪怕大量应用同时发起成百上千个短连接请求也绝不假死、不断流。
  4. **开启 UDP (DTLS) 传输**：原生支持 UDP 高速传输隧道，解决 TCP 的“队头阻塞”，打游戏延迟更低。
- **📱 智能节点下发**：自动生成 `profile.xml`。手机客户端首次成功连接后，自动将域名节点存入列表，下次一键直达。

## 🛠️ 快速安装指南

**支持系统**：Debian 9+ / Ubuntu 18.04+ （暂不支持 CentOS）

### ⚡ 第一步：安装前的准备（非常重要）
1. **准备域名**：请务必提前将你的域名（如 `vpn.example.com`）的 A 记录解析到这台服务器的公网 IP 上。
2. **开放端口**：
   - 请登录云服务商网页控制台（安全组/防火墙），开放 **TCP 80 端口**（用于申请真实证书，否则只能回退自签证书弹红锁）。
   - 开放 **TCP 和 UDP 443 端口**（用于 AnyConnect 的极速通信）。
3. **环境干净**：确保服务器上没有安装 Nginx/Apache/宝塔面板等占用 `80` 端口的网页服务。

### ⚡ 第二步：一键运行脚本
在终端中以 `root` 用户运行以下命令：

```bash
wget -N --no-check-certificate https://raw.githubusercontent.com/lgdglgc/ocserv/master/ocserv.sh && chmod +x ocserv.sh && bash ocserv.sh
```

*(安装完成后，以后只需在终端输入 `bash ocserv.sh` 即可随时唤出图形化管理菜单，进行重启、卸载、增删账号等操作)*

## ⚠️ 避坑排错指南

### 1. 连接时依然弹窗提示“证书不可信” / “证书与服务器名称不符”？
*   **原因 A**：你可能在客户端输入的地址是纯数字 IP。**解决：请务必一字不差地输入你的域名。**
*   **原因 B**：安装时 80 端口没开或解析没生效，导致只生成了自签假证书。**解决：去网页端开放 80 端口，然后重新运行一遍本脚本申请证书。**
*   **原因 C**：手机端存留了以前旧域名/旧IP的缓存配置文件。**解决：在手机 AnyConnect 里将历史连接记录左滑删除，在设置中点击“清除配置信息”，再手动输入新域名重新连接。**

### 2. 连接时提示 `DTLS handshake failed` 并且网速很慢？
*   **原因**：这说明 UDP 隧道建立失败，VPN 被迫降级使用缓慢的 TCP 传输。
*   **解决**：99% 是因为你的云服务器控制台（如阿里云、腾讯云的安全组）只放行了 TCP 的 443，**漏放了 UDP 的 443 端口**。请务必前往网页端手动放行 UDP。

## 📱 客户端推荐

只要支持标准 Cisco AnyConnect 协议的客户端均可连接本服务：

- **Windows / macOS**：搜索下载官方 `Cisco Secure Client`（原 AnyConnect），或者使用开源免费的 `OpenConnect GUI`。
- **Android / iOS**：在应用商店/Google Play搜索安装 `AnyConnect`。

> 💡 **连接方法**：在客户端的“服务器地址”栏，直接输入你的 **域名** 即可连接。
